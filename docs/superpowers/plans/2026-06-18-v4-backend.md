## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 后端框架 | Express | Node.js，端口 4000 |
| LLM | DeepSeek API | 通过 HTTP 调用，需要 API Key |
| 音乐源 | NeteaseCloudMusicApi Enhanced | 开源网易云 API，无需 Key |
| 实时通信 | WebSocket (ws) | 用于状态同步 |
| 数据库 | SQLite (better-sqlite3) | 轻量嵌入式 |
| 前端 HTTP | fetch | 不需要 axios，原生够用 |

## 先搭框架（第一步）

### Part 1：Express 服务骨架

**目标：** 跑通一个 Express 服务，热重载，让前端能访问到

#### 1.1 初始化 server 目录

在 `ai-radio/server/` 下：

```bash
cd server
npm init -y
npm install express cors dotenv
npm install -D nodemon
```

创建 `server/index.js`：

```javascript
const express = require('express');
const cors = require('cors');
require('dotenv').config();

const app = express();
const PORT = process.env.PORT || 4000;

app.use(cors());
app.use(express.json());

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok', name: 'Abyss Radio API' });
});

app.listen(PORT, () => {
  console.log(`🔊 Abyss Radio API running on http://localhost:${PORT}`);
});
```

`package.json` 加脚本：

```json
"scripts": {
  "dev": "nodemon index.js",
  "start": "node index.js"
}
```

**验证：** 访问 `http://localhost:4000/api/health` 返回 `{ status: 'ok' }`

---

#### 1.2 跨域配置（CORS）

前端 `localhost:3000` 访问后端 `localhost:4000`，需要允许跨域。
Express 的 `cors` 中间件已经开了。但 Vite 也需要 proxy：

在 `ai-radio/vite.config.ts` 加 proxy：

```typescript
server: {
  port: 3000,
  proxy: {
    '/api': 'http://localhost:4000',
    '/ws': {
      target: 'ws://localhost:4000',
      ws: true,
    },
  },
}
```

这样前端把 `/api/xxx` 发到 `localhost:3000/api/xxx` 就会自动代理到后端。

### Part 2：前端请求封装

**目标：** 前端有一个统一的 API 调用模块，不再硬编码模拟数据

创建 `ai-radio/src/services/api.ts`：

```typescript
const BASE = ''; // 通过 Vite proxy，空字符串即可

export async function apiGet<T>(path: string): Promise<T> {
  const res = await fetch(`${BASE}${path}`);
  if (!res.ok) throw new Error(`API GET ${path} failed: ${res.status}`);
  return res.json();
}

export async function apiPost<T>(path: string, body: unknown): Promise<T> {
  const res = await fetch(`${BASE}${path}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body),
  });
  if (!res.ok) throw new Error(`API POST ${path} failed: ${res.status}`);
  return res.json();
}
```

**验证：** 前端 `apiGet('/api/health')` 能返回数据

### Part 3：WebSocket 骨架

**目标：** 前后端建立 WebSocket 连接，用于实时状态推送

后端：

```bash
npm install ws
```

`server/ws.js`：

```javascript
const { WebSocketServer } = require('ws');

let wss;

function setupWebSocket(server) {
  wss = new WebSocketServer({ server });

  wss.on('connection', (ws) => {
    console.log('🌐 WebSocket connected');

    ws.on('message', (data) => {
      const msg = JSON.parse(data.toString());
      // 广播或处理
    });

    ws.on('close', () => {
      console.log('🌐 WebSocket disconnected');
    });
  });

  return wss;
}

function broadcast(data) {
  if (!wss) return;
  const msg = JSON.stringify(data);
  wss.clients.forEach((client) => {
    if (client.readyState === 1) client.send(msg);
  });
}

module.exports = { setupWebSocket, broadcast };
```

前端：

```typescript
// src/services/ws.ts
let ws: WebSocket | null = null;

export function connectWebSocket(onMessage: (data: unknown) => void) {
  ws = new WebSocket('ws://localhost:4000/ws');

  ws.onopen = () => console.log('🔌 WS connected');
  ws.onmessage = (event) => onMessage(JSON.parse(event.data));
  ws.onclose = () => {
    console.log('🔌 WS disconnected, reconnecting in 3s...');
    setTimeout(() => connectWebSocket(onMessage), 3000);
  };
}

export function sendWS(msg: unknown) {
  if (ws?.readyState === WebSocket.OPEN) {
    ws.send(JSON.stringify(msg));
  }
}
```

## 后续接入（第二步）

### Part 4：网易云音乐 API

安装：

```bash
npm install @neteasecloudmusicapienhanced/api
```

创建 `server/ncm.js`，提供三个核心函数：

- `searchMusic(keyword)` → 返回歌曲列表（id, 标题, 歌手, 封面, 时长）
- `getMusicUrl(id, level)` → 返回歌曲播放地址
- `getLyric(id)` → 返回歌词（lrc 格式）

**验证：** 搜索"周杰伦"能返回列表，点歌后能拿到播放地址

### Part 5：DeepSeek LLM 接入

创建 `server/deepseek.js`：

```javascript
const DEEPSEEK_API = 'https://api.deepseek.com/v1/chat/completions';

async function chat(messages, apiKey) {
  const res = await fetch(DEEPSEEK_API, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${apiKey}`,
    },
    body: JSON.stringify({
      model: 'deepseek-chat',
      messages: [
        { role: 'system', content: '你是 Abyss Radio 的 AI DJ，负责推荐音乐和与听众聊天。' },
        ...messages,
      ],
    }),
  });
  return res.json();
}
```

需要用户在 `.env` 里放：

```
DEEPSEEK_API_KEY=sk-your-key-here
```
